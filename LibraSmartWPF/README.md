# LibraSmart WPF Desktop Application

Настольное приложение для управления библиотекой на базе WPF и .NET 8.

## Технологический стек

- **WPF (Windows Presentation Foundation)** - UI фреймворк
- **MaterialDesignThemes** - библиотека Material Design UI компонентов
- **Entity Framework Core 8** - ORM для работы с базой данных
- **SQLite** - встраиваемая база данных
- **.NET 8** - платформа разработки
- **BCrypt.Net** - хеширование паролей

## Возможности

### Для читателей:
- Просмотр каталога книг с поиском
- Бронирование книг
- Просмотр своих займов и бронирований
- Управление профилем

### Для персонала библиотеки:
- Управление книгами и экземплярами
- Управление займами (выдача и возврат)
- Управление читателями
- Управление библиотеками
- Просмотр статистики

## Требования

### Для запуска готового приложения:
- Windows 10/11 (64-bit)
- Минимум 100 МБ свободного места

### Для разработки:
- .NET 8 SDK
- Visual Studio 2022 (или JetBrains Rider)
- Windows 10/11

## Установка и запуск

### Вариант 1: Использование готового .exe файла

1. Скачайте файл `LibraSmart.exe` из папки `publish/`
2. Запустите двойным кликом
3. При первом запуске будет создана база данных SQLite с тестовыми данными
4. База данных сохраняется в: `%APPDATA%\LibraSmart\librasmart.db`

### Вариант 2: Сборка из исходников

#### Установка .NET 8 SDK

1. Скачайте .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Установите SDK

#### Клонирование и сборка

```bash
# Перейдите в папку проекта
cd LibraSmartWPF

# Восстановите зависимости
dotnet restore

# Соберите проект
dotnet build

# Запустите приложение
dotnet run
```

## Сборка единого .exe файла

Для создания одного самодостаточного .exe файла (~100 МБ):

### Windows (PowerShell):
```powershell
.\build.ps1
```

### Вручную:
```bash
dotnet publish -c Release -r win-x64 `
  --self-contained true `
  /p:PublishSingleFile=true `
  /p:IncludeNativeLibrariesForSelfExtract=true `
  /p:EnableCompressionInSingleFile=true `
  /p:PublishReadyToRun=true `
  /p:PublishTrimmed=false
```

Готовый файл будет в: `bin/Release/net8.0-windows/win-x64/publish/LibraSmart.exe`

## База данных

Приложение использует SQLite базу данных, которая автоматически создается при первом запуске.

### Расположение БД:
- **Windows:** `%APPDATA%\LibraSmart\librasmart.db`

### Таблицы:
- `roles` - Роли персонала
- `libraries` - Библиотеки (филиалы)
- `staff` - Сотрудники библиотеки
- `readers` - Читатели
- `genres` - Жанры книг
- `books` - Книги
- `book_copies` - Экземпляры книг
- `reservations` - Бронирования
- `loans` - Займы книг

## Особенности реализации

1. **Single File Deployment**: Приложение собирается в один .exe файл, который содержит все необходимые библиотеки и может запускаться без установки .NET runtime.

2. **Автономная работа**: Приложение работает полностью оффлайн, используя встроенную SQLite базу данных.

3. **Material Design**: Современный Material Design интерфейс благодаря библиотеке MaterialDesignThemes.

4. **MVVM Pattern**: Архитектура приложения следует паттерну MVVM для разделения логики и представления.

5. **Безопасность**: Пароли хешируются с использованием BCrypt.

## Устранение проблем

### Приложение не запускается
- Убедитесь, что у вас Windows 10/11 64-bit
- Проверьте, не блокирует ли антивирус приложение
- Попробуйте запустить от имени администратора

### Ошибка при первом запуске
- Убедитесь, что у приложения есть права на запись в папку `%APPDATA%`
- Проверьте наличие свободного места на диске

### База данных повреждена
- Удалите файл `%APPDATA%\LibraSmart\librasmart.db`
- Перезапустите приложение - БД будет создана заново

## Разработка

### Добавление новых страниц

1. Создайте XAML страницу в папке `Views/`
2. Создайте соответствующий ViewModel в папке `ViewModels/`
3. Добавьте пункт меню в `MainWindow.xaml`
4. Добавьте навигацию в `MainWindow.xaml.cs`

### Добавление новых моделей

1. Создайте класс модели в папке `Models/`
2. Добавьте DbSet в `LibraryContext.cs`
3. Настройте связи в методе `OnModelCreating`
4. Обновите `DatabaseInitializer.cs` для тестовых данных
