# 📚 LibraSmart Frontend

Фронтенд для системы управления библиотекой LibraSmart на Vue 3 + Vite + TailwindCSS.

## 🎨 Особенности

- **Vue 3** с Composition API
- **TypeScript** для типобезопасности
- **TailwindCSS** с темно-зеленой темой
- **Vue Router** для навигации
- **Pinia** для управления состоянием
- **Axios** для API запросов
- Полностью **адаптивный** дизайн
- **Полностью на русском языке**

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd front
npm install
```

### 2. Настройка окружения

Создайте файл `.env`:

```bash
cp .env.example .env
```

Для локальной разработки оставьте `VITE_API_URL` пустым (используется прокси).

### 3. Запуск dev-сервера

```bash
npm run dev
```

Откройте http://localhost:3000

### 4. Сборка для продакшена

```bash
npm run build
```

## 🌐 Деплой на Netlify

1. Подключите репозиторий к Netlify
2. Настройте:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
   - **Base directory:** `front`
3. Добавьте переменную окружения:
   - `VITE_API_URL` = URL вашего backend на Render
