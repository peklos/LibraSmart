## 📊 СХЕМА БАЗЫ ДАННЫХ

Я прикрепил два изображения со схемой БД:
1. **Первое изображение** - ER-диаграмма с таблицами и связями
2. **Второе изображение** - Use Case диаграмма с функциональностью

### Основные таблицы (из первого изображения):

1. **roles** - роли библиотекарей
   - id, name

2. **staff** - библиотекари/сотрудники
   - id, full_name, position, library_id, email, password, role_id

3. **libraries** - библиотеки (филиалы)
   - id, library_name, address, phone

4. **readers** - читатели
   - id, full_name, user_id, email, password, phone, library_card_number

5. **genres** - жанры книг
   - id, genre_name

6. **books** - книги
   - id, book_id, title, author, publication_year, genre_id

7. **book_copies** - экземпляры книг (физические копии в библиотеках)
   - id, copy_id, book_id, library_id, inventory_number, status

8. **reservations** - бронирования книг
   - id, reservation_id, reader_id, book_id, library_id, reservation_date, status

9. **loans** - выдачи книг (активные займы)
   - id, loan_id, reader_id, copy_id, staff_id, loan_date, due_date, return_date, status

### 2. Создай модели базы данных (db/models.py)

На основе схемы из первого изображения создай все модели с правильными связями:
- Используй `relationship()` для связей между таблицами
- Добавь индексы для часто используемых полей (email, library_card_number, status и т.д.)
- Используй составные индексы для популярных фильтров

**Связи между таблицами:**
- Staff → Role (Many-to-One)
- Staff → Library (Many-to-One)
- Reader (один читатель может иметь связь с несколькими библиотеками через бронирования)
- Book → Genre (Many-to-One)
- BookCopy → Book (Many-to-One)
- BookCopy → Library (Many-to-One)
- Reservation → Reader, Book, Library (Many-to-One каждая)
- Loan → Reader, BookCopy, Staff (Many-to-One каждая)

### 5. Создай роутеры для ЧИТАТЕЛЕЙ

#### reader_auth.py
- `POST /auth/register` - регистрация
- `POST /auth/login` - вход
- `GET /auth/me/{reader_id}` - получить данные текущего читателя

#### reader_profile.py
- `GET /profile/{reader_id}` - просмотр профиля
- `PATCH /profile/{reader_id}` - обновление профиля

#### reader_books.py
- `GET /books` - каталог всех книг с фильтрацией (по жанру, автору, поиск по названию)
- `GET /books/{book_id}` - детали книги
- `GET /books/{book_id}/availability` - наличие книги в библиотеках

#### reader_reservations.py
- `POST /reservations` - создать бронирование (нужен reader_id в query параметрах)
- `GET /reservations/my/{reader_id}` - мои бронирования
- `DELETE /reservations/{reservation_id}` - отменить бронирование

#### reader_loans.py
- `GET /loans/my/{reader_id}` - мои текущие выдачи
- `GET /loans/my/{reader_id}/active` - активные займы
- `GET /loans/my/{reader_id}/overdue` - просроченные займы

#### reader_history.py
- `GET /history/{reader_id}` - история всех моих выдач (включая возвращенные)
- `GET /history/{reader_id}/stats` - статистика по чтению (сколько книг прочитано, любимые жанры и т.д.)

---

### 6. Создай роутеры для БИБЛИОТЕКАРЕЙ/АДМИНОВ

#### staff_auth.py
- `POST /admin/auth/login` - вход библиотекаря
- `GET /admin/auth/me/{staff_id}` - получить данные текущего сотрудника

#### admin_readers.py
- `GET /admin/readers` - все читатели
- `GET /admin/readers/{reader_id}` - детали читателя
- `POST /admin/readers` - создать читателя
- `PATCH /admin/readers/{reader_id}` - обновить читателя
- `DELETE /admin/readers/{reader_id}` - удалить читателя
- `GET /admin/readers/{reader_id}/loans` - история выдач читателя

#### admin_books.py
- `GET /admin/books` - все книги
- `GET /admin/books/{book_id}` - детали книги
- `POST /admin/books` - добавить книгу
- `PATCH /admin/books/{book_id}` - обновить книгу
- `DELETE /admin/books/{book_id}` - удалить книгу

#### admin_copies.py
- `GET /admin/copies` - все экземпляры
- `GET /admin/copies/library/{library_id}` - экземпляры в конкретной библиотеке
- `POST /admin/copies` - добавить экземпляр
- `PATCH /admin/copies/{copy_id}` - обновить статус экземпляра
- `DELETE /admin/copies/{copy_id}` - удалить экземпляр

#### admin_reservations.py
- `GET /admin/reservations` - все бронирования
- `GET /admin/reservations/active` - активные бронирования
- `PATCH /admin/reservations/{reservation_id}` - обновить статус
- `DELETE /admin/reservations/{reservation_id}` - удалить бронирование

#### admin_loans.py
- `GET /admin/loans` - все выдачи
- `POST /admin/loans` - создать выдачу (выдать книгу читателю)
- `PATCH /admin/loans/{loan_id}/return` - принять возврат книги
- `GET /admin/loans/overdue` - просроченные выдачи
- `GET /admin/loans/active` - активные выдачи

#### admin_staff.py (только для роли "Администратор")
- `GET /admin/staff` - все сотрудники (проверка role_id == 1)
- `POST /admin/staff` - добавить сотрудника
- `PATCH /admin/staff/{staff_id}` - обновить сотрудника
- `DELETE /admin/staff/{staff_id}` - удалить сотрудника

#### admin_libraries.py
- `GET /admin/libraries` - все библиотеки
- `POST /admin/libraries` - добавить библиотеку
- `PATCH /admin/libraries/{library_id}` - обновить библиотеку
- `DELETE /admin/libraries/{library_id}` - удалить библиотеку

#### admin_genres.py
- `GET /admin/genres` - все жанры
- `POST /admin/genres` - добавить жанр
- `PATCH /admin/genres/{genre_id}` - обновить жанр
- `DELETE /admin/genres/{genre_id}` - удалить жанр

#### admin_stats.py

- `GET /admin/stats/popular-books` - топ популярных книг
